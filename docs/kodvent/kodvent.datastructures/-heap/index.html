Heap

class Heap<T>(comparator: Comparator<in T>)(source)

A binary heap, the usual priority queue: its top, which peek returns and pop removes, is the smallest element by the comparator, so Heap<Int>(reverseOrder()) is a max-heap. Equal elements come out in no particular order.

push, pop and replace are O(log n), peek is O(1), and toHeap() builds a heap in O(n). For shortest paths there is kodvent.graph.dijkstra.

A heap is not a collection: toSortedList is the way to see its elements, and two heaps are equal only if they are the same object.

Parameters

comparator

must be a total order in which the place of an element does not change while the element is in the heap. A comparator that reads a distance array the caller keeps lowering breaks this: push (distance, state) pairs instead and skip the stale ones on pop.

val heap = Heap<Int>()
heap.push(5)
heap.push(1)
heap.push(3)

assertEquals(3, heap.size)
assertEquals(1, heap.peek())

val sorted = mutableListOf<Int>()
while (heap.isNotEmpty()) sorted += heap.pop()

assertEquals(listOf(1, 3, 5), sorted)
assertTrue(heap.isEmpty())

fun lowestTotalRisk(grid: Grid<Int>, start: Position, end: Position): Int {
    val dist = MutableGrid(grid.width, grid.height) { Int.MAX_VALUE }
    val heap = Heap<Pair<Int, Position>>(compareBy { it.first })
    dist[start] = 0
    heap.push(0 to start)
    while (heap.isNotEmpty()) {
        val (d, p) = heap.pop()
        if (d > dist[p]) continue // stale entry: p was reached cheaper after this push
        if (p == end) return d
        for (q in grid.neighbors(p)) {
            val nd = d + grid[q]
            if (nd < dist[q]) {
                dist[q] = nd
                heap.push(nd to q)
            }
        }
    }
    error("$end is unreachable from $start")
}

val grid = listOf(
    "1911",
    "1191",
    "9111",
).toGrid { it.digitToInt() }

assertEquals(5, lowestTotalRisk(grid, Position(0, 0), grid.positions.last()))
