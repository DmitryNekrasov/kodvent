class Heap<T>(comparator: Comparator<in T>)

A binary heap, the usual priority queue: its top, which peek returns and pop removes, is the smallest element by the comparator, so Heap<Int>(reverseOrder()) is a max-heap. Equal elements come out in no particular order.

class SegmentTree<T : Any>(source: List<T>, operation: (T, T) -> T)

A segment tree over a copy of source. tree[start, end] combines the elements from start to end, both included and in that order, with operation, and tree[index] = value replaces one element. operation must be associative, like sum, min, max or gcd.
