fun <S> bfs(start: S, neighbors: (state: S) -> Iterable<S>): Map<S, Int>(source)

Breadth-first search from start: returns the fewest steps from start to every state it reaches, with start at 0. A state that cannot be reached is not in the map, and the order of the map is unspecified.

neighbors returns the states one step away from a state and is called once for every reached state. The search visits every reachable state, so in an endless space neighbors has to set a bound. O(V + E) for V reached states and E steps out of them.

A state is any value with stable equals and hashCode, such as a Position, a data class or a list, but not an array, which compares by identity. A state that is itself a collection needs a named argument, bfs(start = listOf(0, 0)).

Samples

val maze = listOf(
    ".#...",
    ".#.#.",
    "...#.",
    "####.",
    "#..#.",
).toGrid()

val steps = bfs(Position(0, 0)) { p -> maze.neighbors(p).filter { maze[it] == '.' } }

assertEquals(12, steps[Position(4, 4)])
assertEquals(-1, steps[Position(1, 4)] ?: -1)

val garden = listOf(
    "AAB",
    "ABB",
    "CCB",
).toGrid()

val seen = mutableSetOf<Position>()
val areas = mutableListOf<Int>()
for (position in garden.positions) {
    if (position in seen) continue
    val region = bfs(position) { p -> garden.neighbors(p).filter { garden[it] == garden[p] } }.keys
    seen += region
    areas += region.size
}

assertEquals(listOf(3, 4, 2), areas)

// Jugs of 3 and 5 liters: fill one, empty one, or pour one into the other
val steps = bfs(0 to 0) { (small, big) ->
    val toBig = minOf(small, 5 - big)
    val toSmall = minOf(big, 3 - small)

    )
}

fun <S> bfs(starts: Iterable<S>, neighbors: (state: S) -> Iterable<S>): Map<S, Int>(source)

Breadth-first search from all of starts at once, each at 0: like bfs from a single start, but the distance of a state is to the nearest of them. A repeated start counts once, and no starts give an empty map. A collection of starts fits both overloads, so name the argument: bfs(starts = sources) { ... }. O(V + E).

Samples

val map = listOf(
    "S...",
    "....",
    "...S",
).toGrid()

val toNearest = bfs(starts = map.positionsOf('S')) { p -> map.neighbors(p) }

assertEquals(0, toNearest[Position(3, 2)])
assertEquals(2, toNearest[Position(3, 0)])
assertEquals(2, toNearest.values.max())
