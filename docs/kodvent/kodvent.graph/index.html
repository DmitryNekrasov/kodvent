Shortest paths over states of any kind, where a lambda returns the neighbors of a state. bfs counts steps and dijkstra sums the costs of steps, from one start or from several.

fun <S> bfs(start: S, neighbors: (state: S) -> Iterable<S>): Map<S, Int>

Breadth-first search from start: returns the fewest steps from start to every state it reaches, with start at 0. A state that cannot be reached is not in the map, and the order of the map is unspecified.

fun <S> bfs(starts: Iterable<S>, neighbors: (state: S) -> Iterable<S>): Map<S, Int>

Breadth-first search from all of starts at once, each at 0: like bfs from a single start, but the distance of a state is to the nearest of them. A repeated start counts once, and no starts give an empty map. A collection of starts fits both overloads, so name the argument: bfs(starts = sources) { ... }. O(V + E).

fun <S> dijkstra(start: S, neighbors: (state: S) -> Iterable<Pair<S, Int>>): Map<S, Int>

Dijkstra's algorithm from start: returns the cost of a cheapest path from start to every state it reaches, with start at 0. A state that cannot be reached is not in the map.

fun <S> dijkstra(starts: Iterable<S>, neighbors: (state: S) -> Iterable<Pair<S, Int>>): Map<S, Int>

Dijkstra's algorithm from all of starts at once, each at 0: like dijkstra from a single start, but the cost of a state is the cheapest from any of them. A repeated start counts once, and no starts give an empty map. A collection of starts fits both overloads, so name the argument: dijkstra(starts = sources) { ... }. O((V + E) log(V + E)).
