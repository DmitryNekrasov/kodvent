MutableGrid

sealed interface MutableGrid<T> : Grid<T> (source)

A Grid whose cells can be overwritten. Its size never changes, and its views show later writes.

Samples

val grid = listOf(
    "..",
    "..",
).toMutableGrid()

grid[Position(1, 0)] = '#'
assertEquals(".#\n..", grid.toString())

val visits = MutableGrid(3, 1) { 0 }
val p = Position(1, 0)
visits[p]++
visits[p] += 1
assertEquals(listOf(0, 2, 0), visits.values)
