Position

data class Position(val x: Int, val y: Int)(source)

A cell position, also used as the offset between two cells. x is the column counted from the left and y is the input line counted from the top, so y grows downward and input[y][x] is the cell at Position(x, y): code written as a[row][column] becomes grid[Position(x = column, y = row)].

Samples

val lines = listOf(
    "....",
    "....",
    ".@..",
)
val grid = lines.toGrid()

val robot = Position(x = 1, y = 2)
assertEquals('@', grid[robot])
assertEquals('@', lines[robot.y][robot.x])

fun manhattanDistanceTo(other: Position): Int

Returns the Manhattan distance to other: |x - other.x| + |y - other.y|. It is computed in Int like the coordinates, so it overflows for two positions more than Int.MAX_VALUE apart.
