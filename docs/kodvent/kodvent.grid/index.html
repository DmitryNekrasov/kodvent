kodvent/kodvent.grid

Package-level declarations

Rectangular grids for puzzle maps: a read-only Grid and a MutableGrid, whose cells are addressed by a Position, and the directions of a step, Direction and Direction8. toGrid parses input lines, and there are functions for neighbors, rays, rotation and wrap-around.

Grid
Link copied to clipboard
sealed interface Grid<out T>

A read-only rectangular grid of width x height cells addressed by Position, where row y holds input line y. It relates to MutableGrid as List does to MutableList, and a grid that is not a MutableGrid never changes. Like a List, it does not freeze a value that is a mutable object.

MutableGrid

sealed interface MutableGrid<T> : Grid<T>

A Grid whose cells can be overwritten. Its size never changes, and its views show later writes.

Position
Link copied to clipboard
data class Position(val x: Int, val y: Int)

A cell position, also used as the offset between two cells. x is the column counted from the left and y is the input line counted from the top, so y grows downward and input[y][x] is the cell at Position(x, y): code written as a[row][column] becomes grid[Position(x = column, y = row)].

fun <T> Grid<T>.toGrid(): Grid<T>

Returns a read-only snapshot that later writes to this grid do not affect. It holds the same value objects, so it is a safe map key only while they do not change. A grid that is not a MutableGrid is returned as it is.

fun List<CharSequence>.toGrid(): Grid<Char>

Returns a grid of the characters of these lines, so lines[y][x] is at Position(x, y). Nothing is trimmed and a space is a cell like any other. An empty list gives a 0 x 0 grid.
