pow

infix fun Long.pow(power: Long): Long(source)

Returns this value raised to power, wrapping around on overflow. As an infix call it binds looser than arithmetic operators: 2L pow n - 1 is 2L pow (n - 1). O(log power).

Throws

IllegalArgumentException

if power is negative

Samples

assertEquals(1024L, 2L.pow(10L))
assertEquals(1024L, 2L pow 10L)
assertEquals(512L, 2L pow 10L - 1) // not 1023: an infix call binds looser than arithmetic

fun Long.pow(power: Long, modulo: Long): Long(source)

Returns this value raised to power modulo modulo. The result is in 0..<modulo, also for a negative base, and exact for every modulo. O(log power) multiplications. Above a modulo of 3,037,000,500, where a product of two remainders could overflow a Long, each multiplication takes O(log modulo) additions.

Throws

IllegalArgumentException

if power is negative or modulo is not positive

Samples

assertEquals(976_371_285L, 2L.pow(100L, 1_000_000_007L))
