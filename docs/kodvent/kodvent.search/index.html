fun <T> List<T>.lowerBound(fromIndex: Int = 0, toIndex: Int = size, comparison: (T) -> Int): Int

Returns the index of the first element in fromIndex..<toIndex for which comparison is not negative, or toIndex if there is none. Along the range comparison must be negative first, then zero, then positive, and any of these three parts may be empty. O(log n).

ternarySearch

inline fun ternarySearch(left: Double, right: Double, f: (Double) -> Double): Double

Returns an approximation of the argument in [left, right] at which f is greatest. f must be unimodal: strictly increasing, then strictly decreasing. The interval is narrowed to 1e-9, or to two adjacent doubles where they are more than 1e-9 apart. Near a smooth maximum the values of f can round to equal doubles, and the result is then less accurate: for x * (20 - x) on 0..20 it is off by about 1e-7, and a large constant added to f makes it worse.
